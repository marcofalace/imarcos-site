MODIFICHE PRINCIPALI
- https://imarcos.it/ resta intenzionalmente completamente vuota.

COME AGGIUNGERE UNO SPONSOR
1. Copiare la locandina in assets/sponsors/.
2. Aprire assets/sponsors.js.
3. Inserire un elemento nel formato indicato nell'esempio commentato.
4. Caricare su GitHub la locandina e il nuovo sponsors.js.

DATI MINIMI NECESSARI PER OGNI SPONSOR
- Nome attività
- File della locandina
- Link completo alla pagina social

La pagina non usa cookie pubblicitari, database o servizi a pagamento.
