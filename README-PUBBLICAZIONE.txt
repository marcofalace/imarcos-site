CONTENUTO DEL PACCHETTO
- index.html: pagina provvisoria di imarcos.it
- lappano-in-passerella/index.html: pagina sponsor dell'evento
- assets/styles.css: grafica
- assets/sponsors.js: elenco sponsor
- assets/sponsors/: cartella per i loghi
- CNAME: collega il sito a imarcos.it

IMPORTANTE
Questo pacchetto non modifica Gmail. I record MX, SPF, DKIM e DMARC non devono
essere toccati. Per il sito cambieranno soltanto i record A del dominio @ e,
se necessario, il CNAME www.

COME AGGIUNGERE UNO SPONSOR
1. Copiare il logo dentro assets/sponsors/
2. Aprire assets/sponsors.js
3. Inserire un oggetto seguendo l'esempio commentato presente nel file
4. Ricaricare i file aggiornati su GitHub

La pagina non usa database, cookie pubblicitari, framework esterni o servizi a
pagamento. Tutti i file necessari sono contenuti nel pacchetto.
